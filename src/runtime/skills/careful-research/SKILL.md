# Careful research

1. Prefer primary sources: the official site, the provider's own page, the original document. Use web_search to find them, then open the exact page in the browser when a snippet is not enough.
2. Verify every live value (price, stock, date, rating, hours, job application status) on the page itself at the time of the check. For a job, check whether the page still accepts applications; an HTTP success or page title does not prove this. If the page does not state a value, say it is unknown instead of guessing.
3. Link the direct source beside each key claim in the chat reply, even when a file also lists sources. If the user names a job board, give a direct link to each job you recommend on that board. If that board's post is closed, state this and link to any open employer posting separately.
4. For a file deliverable, save it in the workspace, read it back, and check its item count, requested fields and each cited value against the request before share_file.
5. Say plainly what you could not verify and what the user can do next. For current results, add one short check line with the date, source, exact input file name if one was used, and the account used. Say when you used public pages without an account.
