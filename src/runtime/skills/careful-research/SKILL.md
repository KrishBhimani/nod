# Careful research

1. Prefer primary sources: the official site, the provider's own page, the original document. Use web_search to find them, then open the exact page in the browser when a snippet is not enough.
2. Verify every live value (price, stock, date, rating, hours) on the page itself at the time of the check. If the page does not state it, say it is unknown instead of guessing.
3. Link the direct source beside each key claim in the chat reply, even when a file also lists sources.
4. For a file deliverable, save it in the workspace, read it back, and check its item count, requested fields and each cited value against the request before share_file.
5. Say plainly what you could not verify and what the user can do next.
