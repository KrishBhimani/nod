# Light and dark theme acceptance

Date: 2026-09-25. The actual production web build was checked in an isolated local profile at 1280 × 720 and 390 × 700. The profile, files, account names and credentials were synthetic.

## Behavior

The desktop sidebar has one theme switch. Mobile keeps icons-only navigation and places the switch in More. The first visit follows the operating system. A selected theme persists across reloads and updates other same-origin windows. A small script applies the theme before React renders. Standalone Browser and secure Vault pages inherit the same palette.

The missing browser icon was caused by absent favicon assets and declarations: the application fallback returned HTML at the icon URL. SVG, ICO and Apple touch icons are now shipped, declared and checked in the built output. The logo keeps the pink brand dot and switches its foreground for the active theme.

## Actual color review

The light palette keeps the warm canvas and plum text. Dark mode uses dark plum surfaces, light text and lighter pink links and actions. It does not invert attached images or documents. The light placeholder color was darkened after its first contrast measurement failed the normal-text threshold.

| Text and background         | Light contrast | Dark contrast |
| --------------------------- | -------------: | ------------: |
| Main text on canvas         |        17.07:1 |       15.93:1 |
| Secondary text on a surface |         6.88:1 |        9.79:1 |
| Muted text on a surface     |         5.30:1 |        7.30:1 |
| Links on a surface          |         5.81:1 |        8.97:1 |
| Primary button text         |         7.85:1 |        8.38:1 |
| Destructive button text     |         6.49:1 |        6.76:1 |

All 68 sampled text/surface pairs passed 4.5:1. The lowest light ratio was 4.504:1; the lowest dark ratio was 6.025:1. These measurements cover the specified semantic token pairs, not a complete accessibility certification of every rendered state.

Visual inspection covered chat text, links, avatars and composer; Apps; Vault rows and editable modal; Goals and Schedule tabs and empty states; Channels and its Telegram form; Inspector with the sidebar open; and image, audio and PDF previews. PDF pages retained their original colors. Gallery arrow-key navigation left focus on the preview and did not outline an arrow button.

On mobile, Apps, Goals, Schedule, Vault and More remained usable at 390 pixels. The document width stayed at 390 pixels and the navigation remained at the viewport bottom. Theme selection survived reload. These checks do not replace testing on every mobile browser or device.
