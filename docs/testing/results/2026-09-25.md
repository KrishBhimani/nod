## Findings

- Initial C01 failed before model invocation because macOS canonicalized the temporary directory from `/var` to `/private/var`, while the isolated workspace adapter used the unresolved path. The harness now resolves the temporary directory before creating adapters. Failure evidence remains in temporary run `sidekick-e2e-KmV6NJ`.
- That failure revealed an absent user-facing failure message. The task stopped but the chat had no explanation. The failure boundary now records one fixed public error per current user segment and a separate redacted developer record; focused regressions cover stale, cancelled and background segments.
- Routing preflight added about 1.8 seconds before the accepted message appeared. The client now renders immediately and reconciles its stable message ID with HTTP and streamed acceptance.

Later sections record additional cases and reruns. Earlier failures remain visible instead of being replaced by a later successful result.
